## 分层边界

Cortex-M 异常入口、自动压栈和 PendSV 是架构层内容；具体启动文件、向量表地址和芯片外设仍需回到 MCU 官方手册。

## 学习路径

从异常模型进入 RTOS 上下文切换，再阅读对应 RT-Thread `libcpu` 端口。不能仅凭 RTOS API 推断汇编行为。
